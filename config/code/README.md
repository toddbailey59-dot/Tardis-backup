# TARDIS Code workspace

Open with `SUPER + SHIFT + E` or:

```sh
~/.local/bin/code /home/doctor/Code/tardis.code-workspace
```

The workspace gathers the main configuration and script folders in one place:

- `Code` — this workspace and notes
- `TARDIS Shell` — `~/.config/quickshell/tardis-shell`
- `Hyprland` — `~/.config/hypr`
- `Scripts` — `~/bin`
- `Wallpapers` — `~/Pictures/wallpapers`

Installed language support:

- Python — `ms-python.python`
- Lua — `sumneko.lua`
- QML — `theqtcompany.qt-qml`, `cutetee.qml`

Custom theme: **TARDIS Dark**.
