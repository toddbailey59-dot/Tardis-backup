# TARDIS Backup

Git-backed snapshot of the TARDIS desktop configuration.

## Included

- `config/quickshell/tardis-shell/` — Quickshell shell source and settings
- `config/hypr/` — Hyprland, hyprpaper, hyprlock, keybinds, workspaces
- `bin/` — wallpaper, local AI, brief, calendar and voice helper scripts
- `config/systemd-user/` — local AI, proxy, brief, calendar and WebUI units
- `config/local-ai/` — tool-call proxy and service template
- `config/morning-brief/` — brief, calendar, voice, tool code and agenda store
- `config/opencode/` — OpenCode local provider config
- `config/code/` — VS Code workspace
- `config/code-user/` — VS Code user settings
- `config/vscode-theme/` — custom TARDIS Dark theme
- `config/kitty/` — Kitty terminal config
- `config/fastfetch/` — fastfetch config and animated text T.A.R.D.I.S logo
- `config/qt6ct/` — Qt appearance config
- `config/sddm/` — TARDIS Gold login theme and SDDM selection override
- `config/grub/` — TARDIS Gold boot theme and active GRUB default
- `config/plymouth/` — TARDIS Gold boot splash and mkinitcpio config
- `docs/` — research notes, local AI, Open WebUI and morning brief guides
- `wallpapers/README.md` — wallpaper pair documentation
- `state/wallpaper-current` — active wallpaper pair name

Large wallpaper JPEGs are intentionally not tracked. Re-download notes are in
`wallpapers/README.md`.

## Usage

Refresh the snapshot and commit:

```sh
~/tardis-backup/backup.sh
```

Commit and push to GitHub, Rassilon and the local mirror:

```sh
~/tardis-backup/backup.sh "update bar" --push
```

Or push the latest commit manually (one push updates both destinations):

```sh
git -C ~/tardis-backup push
```

## Remotes

- `origin` fetches from GitHub and pushes to GitHub, Rassilon and the local
  mirror (three `remote.origin.pushurl` entries, in that order).
- `rassilon` is the SSH bare mirror at `rassilon:tardis-backup.git`
  (10.13.13.6, `~/tardis-backup.git`). Use `git push rassilon` for a
  Rassilon-only push.
- `local` is a bare mirror on this machine at
  `/home/doctor/backups/tardis-backup.git`. Use `git push local` for a
  local-only push.

## Restore

Copy a path back from the repo to its live location, for example:

```sh
cp -a ~/tardis-backup/config/quickshell/tardis-shell/. ~/.config/quickshell/tardis-shell/
cp -a ~/tardis-backup/config/hypr/doctor.lua ~/.config/hypr/doctor.lua
cp -a ~/tardis-backup/bin/. ~/bin/
```

Then reload:

```sh
hyprctl reload
qs ipc -p /home/doctor/.config/quickshell/tardis-shell call tardis reloadShell
```
